# State v. Burton

## Majority (Smith, J. Per Curiam.)

Smith, J.
This was also an indictment against Benjamin Burton for extorting illegal fees from one Roop. The case is precisely similar to the preceding one, and the judgment must be reversed for the same reasons there given.
Per Curiam.
The judgment is reversed with costs. Cause remanded, &c.
